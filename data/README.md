# Dataset

This project uses the **Zepto v2 inventory dataset** with 3,732 source rows and 9 source columns.

Source dataset:
https://github.com/Odongi-s-data-science-projects/Zepto-dataset-SQL/blob/main/zepto_v2.csv

Expected file:
`data/zepto_v2.csv`

The SQL script expects the raw prices in paise and converts them to INR in the `zepto_clean` view.

> The dataset is not currently committed to this repository. Add the CSV locally if you want the project to be fully reproducible from a fresh clone.
